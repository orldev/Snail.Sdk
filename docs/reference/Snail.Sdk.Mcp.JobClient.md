| `TimeSpan Fallback { get; init; }` | How long to go without a notification before the job's resource is read once anyway. A notification can be lost — a transport that dropped it, a session that moved — and a lost one costs a wait of this length, never a hang. Half a minute by default: one read a half-minute, not one every two seconds. |
