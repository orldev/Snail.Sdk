# S3LS0002: Razor output

The code Razor generates for a component is spared RS0041.

| | |
| --- | --- |
| Suppresses | RS0041 (a public API with oblivious reference types) |
| Suppressor | `Released` in `Snail.Sdk.Analyzers` |
| Applies to | files the Razor source generator writes, whose names end in `_razor.g.cs` or `.razor.g.cs` |

## What it suppresses

RS0041 in the code Razor generates: Razor writes `BuildRenderTree` and the rest of a component without nullable
annotations, so every public component of a Razor library would report it.

## What it leaves alone

The same finding in code the repository writes, which stands.

## Why

The finding is about code nobody in the repository wrote and nobody can change.

## Using it

Nothing to do: it applies wherever `Snail.Sdk.Analyzers` runs.
